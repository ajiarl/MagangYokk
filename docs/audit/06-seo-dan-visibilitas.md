## 1. THE FOUR SEO & VISIBILITY AUDIT PILLARS

### PILAR 1: Technical SEO, Robots & Sitemap (Panduan.txt Seksi 21)

#### A. Audit Robots.txt & XML Sitemap
- **Fakta di Codebase:**
  Pemeriksaan direktori `src/app/` dan `public/` menunjukkan:
  - `src/app/robots.ts` atau `public/robots.txt`: **TIDAK DITEMUKAN (HTTP 404)**.
  - `src/app/sitemap.ts` atau `public/sitemap.xml`: **TIDAK DITEMUKAN (HTTP 404)**.
- **Dampak pada Perayapan Mesin Pencari:**
  1. *Crawl Guidance Kosong:* Googlebot dan Bingbot tidak memiliki panduan perayapan, tidak mengetahui jalur mana yang boleh/tidak boleh diindeks, dan tidak dapat menemukan peta situs resmi.
  2. *Discovery Terhambat:* Ketiadaan XML Sitemap menyebabkan bot mesin pencari hanya mengandalkan perayapan pasif, memperlambat proses indeksasi lowongan baru yang baru saja di-scrape.

#### B. Audit URL Canonicalization & Domain Base
- **Fakta di `src/app/layout.tsx`:**
  Objek `metadata` tidak mendefinisikan properti `metadataBase` dan `alternates.canonical`.
- **Risiko Duplikasi Konten:**
  Next.js yang dideploy di Vercel secara otomatis dapat diakses melalui berbagai variasi domain:
  - `magangyokk.com` (domain kustom)
  - `magangyokk.vercel.app` (domain bawaan Vercel)
  - `magangyokk-git-*.vercel.app` (preview URL)
  - URL dengan parameter pencarian (`/?search=react&target=intern`)
  Tanpa tag `<link rel="canonical">`, Google dapat memperlakukan URL-URL tersebut sebagai konten duplikat (*duplicate content split*), yang memecah otoritas peringkat domain.

#### C. Evaluasi SSR vs CSR untuk Bot Crawler
- **Status: Parsial Lolos (Kelemahan Arsitektur Permalinks).**
  - *Sisi Positif:* Karena `src/app/page.tsx` mengeksekusi data fetching di Server Components dan me-render daftar 100 kartu lowongan langsung pada respon HTML awal, Googlebot dapat membaca teks judul dan deskripsi lowongan dalam respon statis pertama tanpa bergantung pada eksekusi JavaScript client.
  - *Kelemahan Kritis (Ketiadaan Dynamic Permalinks):* Seluruh lowongan (100 item) ditumpuk di halaman beranda tunggal (`/`). **Tidak ada halaman detail mandiri** seperti `/loker/[id]` atau `/loker/[slug]`. Hal ini membuat Google tidak dapat mengindeks lowongan spesifik sebagai satu entitas halaman tersendiri.

### PILAR 2: On-Page Metadata, Title & Open Graph (Panduan.txt Seksi 22)

#### A. Cacat Fatal: Metadata Bawaan Scaffold "Create Next App"
- **Fakta di `src/app/layout.tsx:15-18`:**
  ```ts
  export const metadata: Metadata = {
    title: "Create Next App",
    description: "Generated by create next app",
  };
  ```
- **Dampak Kritis terhadap Ranking & SERP:**
  Ini adalah **Cacat Teknis Paling Merusak** pada proyek:
  1. Di hasil pencarian Google, judul website akan muncul sebagai:
     **Create Next App**  
     *Generated by create next app*
  2. Menghancurkan rasio klik pengguna (Click-Through Rate / CTR) karena tampak seperti proyek uji coba amatir yang belum selesai.
  3. Mengabaikan kata kunci primer bernilai tinggi seperti: *"Lowongan Magang IT Indonesia"*, *"Internship Web Developer"*, *"Magang Mahasiswa Informatika"*.

#### B. Ketidaksesuaian Bahasa Dokumen (`<html lang="en">`)
- Pada `src/app/layout.tsx:23`, tag HTML disetel sebagai: `<html lang="en">`.
- **Fakta Konten:** 100% teks antarmuka, judul lowongan, dan deskripsi menggunakan Bahasa Indonesia.
- *Dampak:* Googlebot menggunakan atribut `lang` sebagai salah satu sinyal lokalisasi geografis. Atribut `lang="en"` mengirimkan sinyal kontradiktif yang membingungkan algoritma penargetan bahasa Google.

#### C. Ketiadaan Protokol Open Graph & Twitter Cards
- Aplikasi tidak memiliki deklarasi `openGraph` dan `twitter`.
- **Dampak Sosial & Distribusi:**
  Saat tautan MagangYokk dibagikan oleh mahasiswa di WhatsApp, Telegram, LinkedIn, atau Twitter/X:
  - Tidak ada pratinjau gambar (`og:image`).
  - Tidak ada judul yang menarik (`og:title`).
  - Tampilan yang keluar hanyalah kartu abu-abu polos bertuliskan "Create Next App".

### PILAR 3: Structured Data & Schema.org (Google for Jobs) (Panduan.txt Seksi 23)

Sesuai prinsip `Panduan.txt` Seksi 16 (Baris 605): *"Apakah markup terstruktur sesuai isi halaman?"*

#### A. Evaluasi Google for Jobs Readiness
- **Fakta di Kode:**
  Pencarian sintaksis `<script type="application/ld+json">` pada seluruh direktori `src/` menghasilkan **NOL HASIL**.
- **Peluang Emas yang Hilang:**
  Google memiliki fitur pencarian khusus lowongan kerja (**Google for Jobs**) yang menampilkan kartu lowongan interaktif di bagian paling atas SERP jika halaman memuat schema `JobPosting`.
- Data yang dimiliki MagangYokk sebenarnya sudah sangat kaya:
  - `title`: Judul posisi magang.
  - `company`: Nama perusahaan (`hiringOrganization`).
  - `location` / `is_remote`: Lokasi kerja (`jobLocation` / `applicantLocationRequirements`).
  - `description`: Deskripsi kualifikasi teknis.
  - `scraped_at`: Tanggal rilis (`datePosted`).
  - `is_paid`: Informasi kompensasi (`baseSalary`).
- *Dampak:* Ketiadaan injeksi JSON-LD membuat MagangYokk **100% tidak memenuhi syarat (ineligible)** untuk tampil di fitur Google for Jobs.

## 3. INDEPENDENT ADVISOR VALIDATION (ANTI-FALSE-MISMATCH CHECK)

Sebelum laporan audit Bagian VI ini disahkan, evaluasi independen dijalankan untuk memastikan validitas temuan teknis:

1. **Apakah `title: "Create Next App"` benar-benar ada di kode produksi saat ini?**
   - *Validasi:* **100% Terverifikasi**. Berkas `src/app/layout.tsx` baris 15-18 secara harfiah tertulis:
     `title: "Create Next App", description: "Generated by create next app"`.
     Ini adalah kelalaian setup awal paling mencolok yang masih tersisa di kode produksi.
2. **Apakah Google for Jobs dapat menerima Schema `JobPosting` pada halaman listing agregator?**
   - *Validasi:* **Bisa dengan format ItemList atau Single Permalinks**. Google mengizinkan injeksi schema `JobPosting` pada halaman utama jika data pekerjaan tersedia lengkap di DOM, namun Google sangat merekomendasikan setiap lowongan memiliki URL permanen unik. Klasifikasi sebagai *Peluang Emas yang Hilang* adalah tepat.
3. **Apakah Next.js 16 secara otomatis membuat robots.txt jika tidak disediakan file?**
   - *Validasi:* **Tidak**. Next.js App Router hanya menyajikan robots.txt dan sitemap.xml jika pengembang membuat berkas konvensi `robots.ts` atau `sitemap.ts` (atau meletakkan file statis di folder `public/`). Tanpa berkas tersebut, endpoint mengembalikan HTTP 404.

## 4. KESIMPULAN REKAYASA & ACTIONABLE BLUEPRINT

Kondisi SEO MagangYokk saat ini berada pada tahap **kritis tanpa visibilitas (Near-Zero Search Engine Readiness)** akibat bocornya metadata default scaffold Next.js.

### 3 Langkah Cepat Perbaikan (Quick Wins):
1. **Perbaiki Metadata & Open Graph (`src/app/layout.tsx`):**
   ```ts
   export const metadata: Metadata = {
     metadataBase: new URL("https://magangyokk.com"),
     title: {
       default: "MagangYokk — Platform Pencari Magang & Lowongan IT Indonesia",
       template: "%s | MagangYokk"
     },
     description: "Agregator lowongan magang tech stack modern (Next.js, React, Laravel, Supabase) dengan AI Cover Letter otomatis dan Kanban tracking pelamar.",
     keywords: ["magang IT", "internship web developer", "magang mahasiswa", "lowongan IT Indonesia"],
     alternates: { canonical: "/" },
     openGraph: {
       title: "MagangYokk — Temukan Magang IT Sesuai Tech Stack Kamu",
       description: "Filter cerdas, scoring otomatis, dan buat cover letter instan via AI.",
       url: "https://magangyokk.com",
       siteName: "MagangYokk",
       locale: "id_ID",
       type: "website"
     }
   }
   ```
2. **Terbitkan `src/app/robots.ts` & `src/app/sitemap.ts`:**
   Manfaatkan generator metadata bawaan Next.js 16 untuk otomatisasi crawling.
3. **Injeksi Schema `JobPosting` (Google for Jobs):**
   Susun komponen `<script type="application/ld+json">` yang memetakan array lowongan ke standar Schema.org.
